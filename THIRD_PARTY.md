# Código y recursos

El código del generador procede de wardice-warmachine-data y conserva su licencia MIT y aviso de copyright. Los colores de facción se trasladaron de wardice-hud; no hay dependencia de ese proyecto al ejecutar.

La licencia del código no concede derechos sobre reglas, marcas, ilustraciones, iconos ni otros contenidos de Warmachine App. El repositorio no incluye sus bundles, texturas, retratos, fuentes ni exportaciones.

Las dos texturas originales de espirales se extraen en el equipo del usuario desde resources.assets y se guardan en .local/assets (ignorado por Git). Los JSON de geometría describen las posiciones utilizadas por el adaptador para conservar la lectura de las espirales.

Las dependencias Python mantienen sus propias licencias. Se instalan desde PyPI; no se redistribuyen sus binarios en el repositorio. Arial y Segoe UI se leen de la instalación de Windows.

Herramienta comunitaria independiente; sin afiliación ni aprobación oficial.
